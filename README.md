# Smart Expense Tracker

## Overview

**Smart Expense Tracker** is a personal finance management application designed to help users track income, expenses, savings, and financial goals in one place. The application enables users to manage daily transactions, categorize expenses, monitor spending patterns, and plan savings based on specific financial goals.

Users can set a financial goal by defining the target amount and completion date. Based on these inputs, the application generates a personalized monthly savings plan to help users achieve their goals in a structured manner.

An interactive dashboard provides financial summaries and visual insights into income, expenses, savings progress, remaining balance, and spending patterns, supporting better financial decision-making.

## Key Features

* Secure user registration and login
* Add, edit, and delete income and expense transactions
* Categorize expenses for better financial organization
* Track total income, expenses, savings, and remaining balance
* Set financial goals with target amount and completion date
* Generate personalized monthly savings plans
* Track progress toward financial goals
* Search and filter transaction history
* Interactive dashboard with charts and financial summaries
* Responsive and user-friendly interface

## Objective

The objective of the **Smart Expense Tracker** is to help users develop better financial habits through effective expense management and goal-based savings planning. By combining transaction tracking, financial analysis, and personalized savings recommendations, the application helps users make informed financial decisions and work toward their financial goals in a structured manner.

## Technologies Used

* **Frontend:** React.js, CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT
* **Machine Learning:** Python
* **Charts & Visualization:** Recharts
* **API Communication:** REST APIs, Axios
* **Tools:** Git, GitHub, VS Code
